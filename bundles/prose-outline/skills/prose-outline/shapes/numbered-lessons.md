---
name: numbered-lessons
mode: argument
parts:
  - intro | required | 0.05-0.15
  - lesson | required | 0.65-0.90
  - close | required | 0.05-0.15
good_for: newsletter, linkedin-post, blog-post
length_hint: 400-2500
---
An introduction that says where the lessons come from, then a run of numbered
lessons, each with its own example, then a close that ties them together. The
`lesson` part repeats, one node per lesson. It works when the material really
is several separate things learned from one experience. It fails when the
lessons are the same lesson restated, or when the numbers are doing the work an
argument should.
